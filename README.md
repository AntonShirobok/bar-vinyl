# 🎵 Винил бара

Telegram Mini App: каталог винила бара. Отдельный проект, с bar-bot не связан.

**Что умеет**
- Каталог с обложками: поиск, полки, десятилетия, темп (BPM), сортировка.
- Карточка пластинки: год, BPM, полка, жанры, «похожее на полках».
- «Что поставить?»: 8 настроений, по каждому три пластинки разных исполнителей.
- Избранное ♡: хранится в облаке Telegram гостя (CloudStorage) и в браузере.

**Как устроено**
- `index.html`, `styles.css`, `app.js` — сама страница, лежит на GitHub Pages.
- `config.js` — ссылка на Apps Script (`API_URL`).
- `gas/Code.gs` — Google Apps Script внутри таблицы: отдаёт каталог (кеш 5 минут).
- `data/vinyl.json` — запасная копия каталога, если таблица недоступна.
- `data/covers.json` — найденные обложки (iTunes, Deezer). Для новых пластинок приложение ищет обложку само.

**Обновить обложки после добавления пластинок**
```
python tools/xlsx_to_json.py путь\к\выгрузке.xlsx
python tools/fetch_covers.py
```

**Запустить локально:** `python -m http.server 8765` в папке проекта, открыть http://localhost:8765.

Настройка с нуля: [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).
